# Changelog

## 1.0.0 — 2026-10-29

- Package the existing four-model bicycle paint studio as a standalone static project.
- Add English UI, translated palettes, accessible labels and remembered language choice.
- Add explicit local save/restore for model, paint mode and colors.
- Separate styles and translation resources from the rendering implementation.
- Add bilingual documentation, contribution guidance, code/asset licensing boundaries and Pages automation.

The photo-derived renderings retain their existing masking approximations. This release does not claim physical paint accuracy.
