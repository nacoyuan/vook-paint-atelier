# VOOK 自行车配色工作室

[English](README.md) · 中文

基于原生 JavaScript 和 Canvas 的轻量自行车配色工具。提供四款实车预览、纯色与渐变、图片吸色及海报导出。无需账户和后端，不上传参考图片，不使用分析追踪。

## 本地运行

安装 Python 3 后，在项目目录执行：

```sh
python3 -m http.server 8000 --directory site
```

浏览器打开 http://localhost:8000。建议通过本地 HTTP 服务运行，避免直接打开文件时的 Canvas 跨域限制。

## 使用方法

1. 选择 V9、V8 碳轮版、ONE 3.0 或 CRV。
2. 使用灵感方案，或选择车架、前部、Logo 独立调色；支持输入十六进制色号。
3. 添加本地图片，点击吸色，悬停放大；也支持拖放和粘贴。
4. 保存配色到本机，之后可以恢复；切换语言前可先保存当前设计。
5. 导出海报：桌面为 2400 × 1600 横版，手机为 1080 × 1920 竖版。

中英文界面根据浏览器语言初始化，也可手动切换；选择会在本机记住。参考图片只在当前页面内处理，不写入保存记录。

## 开发与部署

`site/` 为完整静态站点，`app.js` 负责涂装渲染，`i18n.js` 集中管理文案。无需安装前端依赖。执行 `python3 scripts/check.py` 检查静态资源。GitHub Actions 检查后可发布 `site/` 至 GitHub Pages；首次需在仓库 Settings → Pages 选择 GitHub Actions。

新增车型需提供对齐的 1536 × 1024 底图、蒙版和光影图，在 `modelAssets`、`modelInfo` 和下拉框中注册；用浅色、深色和高饱和色检查边界。贡献前请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
