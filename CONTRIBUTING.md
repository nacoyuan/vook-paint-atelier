# Contributing

Please open an issue describing the user problem before large changes. Small fixes and translation improvements are welcome directly as pull requests.

Run the static server described in README and `python3 scripts/check.py`. Verify Chinese and English, all four models, solid/gradient painting, logo colors, palette expansion, hex entry, image sampling, local save/restore, and poster exports. Check a narrow phone viewport and keyboard navigation. Include screenshots for visual changes and state which checks were actually performed.

Keep the application free of runtime dependencies, tracking and remote uploads. Never commit secrets, deployment credentials, personal paths, downloaded source advertisements or local reference images. New visual assets need documented provenance and redistribution permission. Code contributions are MIT licensed; third-party asset rights remain separate.
