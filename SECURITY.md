# Security

This application is a static browser tool without a backend or account system. Uploaded reference images stay in memory; saved designs contain only model, paint mode and hex colors in localStorage. Local storage is scoped to the hosting origin.

Do not post credentials or private reference images in issues. For a security concern, use GitHub private vulnerability reporting if enabled; otherwise contact the repository owner through their public GitHub profile before publishing exploit details. Keep browsers up to date and serve production copies over HTTPS.
